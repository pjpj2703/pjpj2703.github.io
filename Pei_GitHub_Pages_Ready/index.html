the way.

A place to keep the context behind the work — concepts, questions, and lessons I want to return to.

Reading campaign results in context

In an academic advertising simulation, I practiced comparing clicks, conversions, revenue, and ROAS. A useful review connects each metric to the campaign objective and the budget used, rather than judging success from one number alone.

Questions to revisit: What changed between rounds? Which keywords underperformed? What evidence supported the next budget decision?

Looking beyond the page view

My UNO student worker role included using GA4 Explore to examine user paths and application funnels. This provided a way to investigate how visitors moved through university webpages alongside reviewing traffic and engagement reports.

Questions to revisit: What was the audience trying to do? Where did a path end? What could the data show, and what would require further investigation?

Documenting an AI-assisted build

My personal projects include an AI-assisted availability tracker and multiplayer game. A clear project record separates the goal, AI assistance, my own testing and decisions, and the limitations of the final result.

Questions to revisit: What did I ask the tool to build? What did I test myself? Which issues did I identify and how were they addressed?

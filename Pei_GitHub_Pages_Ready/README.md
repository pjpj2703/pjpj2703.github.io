# Pei Chieh Wu — Portfolio

## 上線步驟
1. 在 GitHub 建立 Public repository，名稱必須是 `pjpj2703.github.io`。
2. 解壓縮此資料夾，將 **資料夾裡的內容**（index.html、styles.css、projects.js、site.js、assets 等）上傳到 repository 根目錄，不要多包一層資料夾。
3. Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 網址為 https://pjpj2703.github.io/ 。等待 GitHub 的部署完成後再檢查。

## OpenClassrooms 原始 ZIP
此檔約 44 MB，不放進網頁上傳包；保留原始 ZIP，不需要解壓縮。
1. repository → Releases → Create a new release。
2. tag 填 `portfolio-files-v1`；release title 可填 `Portfolio project files`。
3. 將原始 ZIP 的檔名改成 `OpenClassrooms-Marketing-Research.zip`，上傳為 release 附件。
4. Publish release。網站下載按鈕已指向這個附件地址；release 發布前連結尚不可用。

## 之後如何修改
- 專案文字、圖片路徑、排序：projects.js（每個專案是一組資料；整組移動可調順序）。
- 首頁、About、證書與聯絡方式：index.html。
- 顏色和版面：styles.css。
- 分類與互動：site.js，通常不需要改。
- 圖片與證書：assets/。

不需要 Python、npm 或編譯。下載後可直接用瀏覽器開 index.html。
公開發布前請確認所有報告及圖片均適合公開，包括原始 ZIP 裡的資料。
